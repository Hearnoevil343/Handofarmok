Glass Inspector look

Second of three looks. Same map, same brushes, same keys as Fortress. Only the frame moves: the map fills the window and everything floats over it.

Layout: pages float top left, look switcher top right. Layers, view toggles and the tile under your cursor live in one inspector on the right, so there's no status bar.

Colours: dark see-through panels, one teal accent for anything selected, soft red for warnings.

Same keys: 1–6 layers, F1–F6 pages, WASD and arrows move the map.
