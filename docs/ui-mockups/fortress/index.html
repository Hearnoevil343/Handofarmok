Fortress look

First of three looks. The map and brushes work exactly as today; only the frame changes. Rough mockup for approval, not the final pixels.

Colours: Dwarf Fortress's 16 text colours, toned down a little. Yellow marks what's selected, green headings, cyan hotkeys, red warnings.

Type: a DOS-style font for titles only; everything you read is a clean monospace.

Symbols: the mark is mountain, tree and water as DF draws terrain in text mode. Headings use ►.

Keys: 1–6 pick layers, F1–F6 switch pages, WASD and arrows only move the map.

Look switcher: top right. Fortress now; Glass Inspector next; Cartographer last.
