# Britannia preset — map data credit

`britannia.json.gz` (and everything built from it: the Britannia recipe, the height/coast/river
data, and the generated preset output) is derived from the Ultima VI surface map:

- Otmar Lendl's tile-id map of the Ultima VI surface,
  https://lendl.priv.at/~lendl/ultima/ultima6/brit.raw.gif (one pixel per game tile),
  shared with "Share and enjoy"; no licence stated.
- Andrew Jenner's Ultima VI tile sheet, http://www.reenigne.org/computer/u6maps/u6tiles.png,
  used to identify which tiles are water, grass, forest, swamp, mountain and desert;
  no licence stated.
- Place coordinates from the Ultima Codex "Ultima VI teleportation" page.

Neither map source states a licence, so this preset is shared for non-commercial use only,
with credit to both. Ultima, Britannia and their places are copyright Origin Systems /
Electronic Arts.
